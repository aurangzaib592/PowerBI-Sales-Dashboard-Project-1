# 📊 Power BI Sales Dashboard Project

## 📌 Project Overview
This project is a professional Sales Dashboard built in Microsoft Power BI using the Sample Superstore dataset. It provides interactive insights into sales, profit, profit margin, customer segments, categories, cities, and yearly performance.

## 🎯 Objectives
- Analyze Sales Performance
- Compare Current Year vs Previous Year
- Track Profit and Profit Margin
- Identify Top Performing Cities
- Analyze Category and Segment Performance

## 🛠️ Tools Used
- Microsoft Power BI
- Power Query
- DAX
- Data Modeling
- Microsoft Excel

## 📈 Dashboard Features
- Total Sales Card
- Total Profit Card
- Profit Margin Card
- KPI Cards with Previous Year Comparison
- Sales Trend Analysis
- Category Analysis
- Segment Analysis
- City Analysis
- Interactive Filters

## 📂 Dataset
Sample Superstore Dataset (.xls)
